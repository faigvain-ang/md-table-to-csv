De tablas Markdown a CSV sin alterar las comas decimales

Seleccione la tabla correcta y revise cadenas, comillas y tuberías escapadas en una exportación real.

Mantenimiento: Equipo de mantenimiento de faigvain-angPublicado: 2026-11-03 · Actualizado: 2026-11-04

Localice la tabla antes de exportarla

La muestra sintética examples/table-sample.md contiene dos tablas: ingresos por país y un extracto de flujos de efectivo. La primera incluye acentos, comas decimales, una tubería escapada y otra dentro de código inline. Ninguna debe crear una columna CSV adicional.

git clone https://github.com/faigvain-ang/md-table-to-csv.git
cd md-table-to-csv
python md_table_csv.py examples/table-sample.md --list
python md_table_csv.py examples/table-sample.md --table 1 --output out/revenue.csv

Basta Python 3.11+; no se instalan paquetes. El listado muestra la tabla 1 con encabezados Country, Revenue y Note, y dos filas de datos. La numeración empieza en 1, no en 0.

Revise el texto producido

Country,Revenue,Note
España,"1.234,50",audited | draft
México,"900,25",`A|B`

Las comillas alrededor de 1.234,50 pertenecen al formato CSV. Un lector CSV recibe una sola celda con esa cadena exacta. La herramienta no presupone que la coma sea decimal, no quita separadores de miles ni deduce una moneda. No convierte el valor en 1234.50.

El escape Markdown en audited \| draft se transforma en una tubería literal. Por defecto conserva las comillas invertidas del código; añada --text si desea quitar envolturas simples de código/enlace. Con --all --output-dir out/tables exporta todas las tablas compatibles; la de flujos se guarda como table-002.csv.

Importe con la configuración correcta

Seleccione UTF-8 y separador coma. La hoja de cálculo aún puede reinterpretar fechas o números, de modo que conviene marcar las columnas como texto si importa conservarlas. Las comillas CSV no impiden ejecutar fórmulas; lea la nota metodológica sobre fórmulas antes de abrir celdas no fiables.

El servicio relacionado KolmoPDF puede realizar una etapa previa de PDF a Markdown en la nube, pero este CLI empieza con un archivo Markdown local y no lo llama. La muestra se redactó directamente, no procede de un PDF de cliente.
