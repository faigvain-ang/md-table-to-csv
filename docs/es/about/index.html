Acerca de Table Workshop

Table Workshop explica el paso entre una tabla Markdown y un CSV que pueda revisar. Los ejemplos conservan comas decimales y Unicode, explican las tuberías escapadas y el código inline, y permiten elegir explícitamente cómo tratar posibles fórmulas.

Si la fuente es un PDF, KolmoPDF PDF a Markdown puede realizar la conversión previa. Ese servicio en la nube carga el documento; el exportador de tablas procesa el Markdown local resultante. Compruebe las cifras importantes en la fuente antes de calcular.

https://github.com/faigvain-ang/md-table-to-csv · MIT
