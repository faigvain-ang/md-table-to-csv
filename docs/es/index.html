LOCAL / OPEN SOURCE

Un pequeño banco de exportación

Python 3.11+, sin paquetes externos. Exporte una tabla o todas las compatibles. Por defecto conserva las cadenas de las celdas.

Código en GitHub →
python md_table_csv.py examples/table-sample.md --list
python md_table_csv.py examples/table-sample.md --table 1 --output out/revenue.csv

Descargue el código y los ejemplos sintéticos. Sin cargas ni llamadas a la nube.

¿Parte de un PDF y no de un archivo Markdown? El servicio KolmoPDF PDF a Markdown realiza la conversión previa en la nube y carga el documento. Este exportador abierto solo procesa el Markdown ya guardado en local.
