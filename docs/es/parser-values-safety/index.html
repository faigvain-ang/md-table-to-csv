Un dialecto de tablas deliberadamente pequeño

El analizador exige celdas de una línea, al menos dos columnas y una fila separadora con tres guiones como mínimo por celda. Admite dos puntos de alineación y tuberías exteriores opcionales. Excluye los bloques de código vallados, para no exportar una muestra de documentación como si fuera una tabla real.

Las tuberías escapadas y las incluidas en código con comillas invertidas equilibradas pertenecen a la celda. Admite delimitadores de varias comillas invertidas. Es una comodidad intencionada: algunos dialectos Markdown exigen escapar tuberías incluso en código. No implica conformidad completa con GFM o CommonMark.

| Expression | Note |
| --- | --- |
| `A|B` | draft \| final |

# Dos celdas: `A|B` y draft | final

No reparar por suposición

Si una fila tiene un número de celdas distinto al encabezado, produce un error. No adivina el valor que falta ni descarta una columna sobrante. No admite celdas combinadas, tablas HTML, celdas multilínea o tablas anidadas en citas/listas. Repare el origen de forma explícita o utilice otro formato.

Primero conservar, después elegir la política de seguridad

El CSV predeterminado conserva marcado inline y cadenas numéricas, salvo espacios exteriores y escapes de tuberías. No hay conversión regional. --text solo quita envolturas simples de código/enlace; no sanea HTML ni renderiza documentos completos.

Las comillas CSV no impiden que una hoja ejecute una fórmula. --spreadsheet-safe añade un apóstrofo cuando el primer carácter no blanco es =, +, - o @. También afecta a negativos: -20 pasa a '-20. Elija la opción conscientemente y conserve una copia sin cambios para conciliar. Es una precaución, no una garantía para todas las hojas de cálculo.

El exportador no determina si una cifra se extrajo bien. Compare las celdas importantes con la fuente antes de calcular.

Si una celda es incorrecta por una extracción previa del PDF, revise o repita esa etapa antes de exportar. El conversor relacionado KolmoPDF PDF a Markdown es una opción separada en la nube que carga el PDF. Este analizador local no lee el PDF ni certifica la correspondencia de una cifra con su fuente.
