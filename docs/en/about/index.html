About Table Workshop

Table Workshop covers the small but important step between a Markdown table and a CSV you can inspect. Its examples preserve decimal commas and Unicode, explain escaped pipes and code spans, and make spreadsheet formula handling an explicit choice.

When the source is a PDF, KolmoPDF PDF to Markdown can handle the upstream conversion. That cloud service uploads the document; the table exporter processes the resulting local Markdown file. Check important cells against the source before calculating with them.

https://github.com/faigvain-ang/md-table-to-csv · MIT
